# Focal (聚点)

> **Slogan:** *Your interest, the world's Focal.*

零服务端、纯端侧聚合（Client-Side Aggregation）、Google Material 3 现代规范交互的 Android 应用。

---

## 一、 核心痛点与解法
1. **解决痛点**:
   - 告别在多个独立 App 之间反复横跳切换。
   - 告别各平台频繁扫码与繁琐账户登录管理。
   - 打破算法茧房，真正由用户自主定制感兴趣的栏目（娱乐、体育、科技、财经、国际等）。
   - 全网跨平台热度归一化融合呈现，不再被单一平台信息孤岛局限。

2. **核心业务板块 (极简单字意象与纯图标化导航)**:
   - **阅** (News & Rankings): 全网热度归一化排行榜，集成**今日头条、微博、百度、知乎、Reddit、HackerNews**，支持按用户自定义栏目（综合、娱乐、体育、科技、财经、全球）过滤与优雅缩略图呈现。
   - **视** (Watch): 抖音竖屏短视频与 Bilibili 横屏长视频无缝流式浏览，16:9 标准比例视频缩略图与居中轻质感播放。
   - **听** (Listen): **番茄畅听、喜马拉雅热播榜**与公开科技播客，唱片质感缩略图，集成 Media3 常驻后台与悬浮微胶囊控制。
   - **问** (Ask): 豆包、Kimi、通义千问、腾讯元宝一键同问，多模态实时卡片对比。
   - **设** (Settings): 侧边手势/图标呼出的独立抽屉，支持**背景壁纸定制、透明度/对比度实时微调**、栏目偏好定制、全网源开关与 AI 身份对接持久化。

## 二、 UI/UX 架构亮点 (遵循 Material 3 官方设计体系)

### 1. 干净简约高级的 M3 设计语言
- **动态色彩体系 (ColorScheme)**：完全拒绝硬编码 `#` 开头色值，严格从 `MaterialTheme.colorScheme` 读取，支持应用内主题自适应与切换。
- **官方规范矢量图标**：统一标准尺寸 24dp，线条粗细一致，跟随主题动态自适应变色。
- **全局圆角规范**：卡片统一圆角 12dp，常规按钮 8dp，小标签 4dp，胶囊 20dp，规整一致。
- **柔和轻阴影**：卡片 elevation 控制在 1~2dp，轻盈透光，无生硬发黑阴影。
- **间距与留白**：固定 16dp 安全边距，8dp/16dp 栅格模数对齐，留白充足无错位。
- **文字层级 (Roboto)**：大标题 18sp 加粗，正文 14sp，辅助说明文字 12sp，清晰易读。
- **交互动效**：淡入淡出过渡动画 (`AnimatedContent`)，加载占位骨架屏 (`M3SkeletonCard`)，按压水波纹触摸反馈。

### 2. 沉浸式壁纸与透明度/对比度滤镜工坊 (Wallpaper Filter Engine)
- 在侧边抽屉中内置画境配置：
  * 支持壁纸预设切换（竹影、水乡、落日、纯粹等）；
  * **透明度滑块 (0.1 ~ 1.0)**：动态控制背景透光度，卡片背后的意境自然漫透；
  * **对比度滑块 (0.5 ~ 1.5)**：通过底层 `ColorMatrix` 进行动态对比度调节；
  * 配置持久化保存，冷启动无缝还原。

## 三、 工程结构
```
focal-android/
├── app/
│   ├── src/main/
│   │   ├── AndroidManifest.xml       # 声明前台音频播放服务与网络权限
│   │   └── java/com/focal/app/
│   │       ├── MainActivity.kt        # M3 主容器与动态壁纸/对比度滤镜容器
│   │       ├── core/
│   │       │   ├── navigation/        # 阅/视/听/问 纯图标意象枚举
│   │       │   ├── network/           # 统一端侧 OkHttp 网络客户端
│   │       │   ├── storage/           # 偏好配置与硬件加密身份持久化
│   │       │   └── theme/             # M3 ColorScheme、Dimens度量与Wallpaper容器
│   │       ├── feature_read/          # 「阅」全网热度排行榜与缩略图卡片
│   │       ├── feature_watch/         # 「视」16:9卡片视频流 (抖音 + B站)
│   │       ├── feature_listen/        # 「听」唱片质感后台常驻音频流与胶囊控制
│   │       ├── feature_ask/           # 「问」多AI同问对比引擎
│   │       └── feature_set/           # 「设」侧边抽屉设置与壁纸微调面板
│   └── build.gradle.kts
├── settings.gradle.kts
└── local.properties
```
