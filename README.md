# Focal (聚点)

> **Slogan:** *Your interest, the world's Focal.*

零服务端、纯端侧聚合（Client-Side Aggregation）、高审美极简图标化交互的 Android 应用。

---

## 一、 核心痛点与解法
1. **解决痛点**:
   - 告别在多个独立 App 之间反复横跳切换。
   - 告别各平台频繁扫码与繁琐账户登录管理。
   - 打破算法茧房，真正由用户自主定制感兴趣的栏目（娱乐、体育、科技、财经、国际等）。
   - 全网跨平台热度归一化融合呈现，不再被单一平台信息孤岛局限。

2. **核心业务板块 (极简单字意象与纯图标化导航)**:
   - **阅** (News & Rankings): 全网热度归一化排行榜，集成**今日头条、微博、百度、知乎、Reddit、HackerNews**，支持按用户自定义栏目（综合、娱乐、体育、科技、财经、全球）过滤与呈现。
   - **视** (Watch): 抖音竖屏短视频与 Bilibili 横屏长视频无缝流式浏览与播放。
   - **听** (Listen): **番茄畅听、喜马拉雅热播榜**与公开科技播客，集成 Media3 常驻后台与锁屏/通知栏胶囊控制。
   - **问** (Ask): 豆包、Kimi、通义千问、腾讯元宝一键同问，多模态实时卡片对比。
   - **设** (Settings): 侧边手势/图标呼出的独立抽屉，不挤占主界面空间；支持栏目偏好定制、全网源开关与 AI 身份对接持久化。

---

## 二、 核心架构亮点

### 1. 资讯全网热度归一化引擎 (Cross-Platform Heat Ranker)
- 并发向今日头条、微博热搜、百度热搜、知乎热榜、Reddit 与 HackerNews 发起端侧聚合。
- 基于平台指数进行统一标尺归一化（0~1000万+），按用户选定栏目融合排序，优先呈现全网最爆内容。

### 2. 极致图标化设计语言 (Icon-Driven UI)
- 贯彻**东方美学与新中式深空留白**（浓墨、玄灰、竹青、月白），界面去掉所有臃肿冗余的标题修饰。
- 主导航与操作全面采用精准直观的矢量微标（Vector Icons），能用图标标识的地方绝不出现冗余描述。

### 3. 侧边独立展开的设置抽屉 (Slide-out Drawer)
- 设置模块完全从主屏幕解耦，常态下彻底隐藏，最大化呈现内容本身。
- 用户可定制：**感兴趣的栏目开关**、各平台源开关、以及 AI 身份持久化管理。

### 4. 听书矩阵全网扩充
- 涵盖国内主流有声书源（**番茄畅听热榜**、**喜马拉雅热播榜**）与全球开放播客。
- 常驻后台播放与状态保活。

### 5. AI 身份对接持久化工具 (Auth Bridge)
- 提问直接可用，彻底告别开发者 API Key 的繁琐申请。
- 提供内置隔离 WebView 身份桥：用户登录后，自动捕获 Session/Cookie，使用 Android Jetpack 硬件级 `EncryptedSharedPreferences` (AES-256-GCM) 持久化于本地。
- 支持并发协程向选中的多个 AI 模型发起流式问答，并排呈现各家回答差异，方便比对决策。

## 三、 工程结构
```
focal-android/
├── app/
│   ├── src/main/
│   │   ├── AndroidManifest.xml       # 声明前台音频播放服务与网络权限
│   │   └── java/com/focal/app/
│   │       ├── MainActivity.kt        # 纯图标单 Activity 骨架与侧边抽屉托管
│   │       ├── core/
│   │       │   ├── navigation/        # 阅/视/听/问 纯图标意象枚举
│   │       │   ├── network/           # 统一端侧 OkHttp 网络客户端
│   │       │   ├── storage/           # 栏目偏好与硬件加密身份持久化
│   │       │   └── theme/             # 东方美学水墨色系与主题
│   │       ├── feature_read/          # 「阅」全网热度归一排行榜与栏目筛选
│   │       ├── feature_watch/         # 「视」长短视频卡片流 (抖音 + B站)
│   │       ├── feature_listen/        # 「听」番茄畅听/喜马拉雅/播客后台常驻播放
│   │       ├── feature_ask/           # 「问」多AI同问对比引擎
│   │       └── feature_set/           # 「设」侧边抽屉与 AuthBridge 身份对接沙箱
│   └── build.gradle.kts
├── settings.gradle.kts
└── local.properties
```
